# ManMadhan Progress — Enterprise Backend Infrastructure

Enterprise-scale Node.js backend workspace configured with Express, TypeScript, PostgreSQL (Drizzle ORM), SMTPS/Email services, Redis BullMQ queues, Socket.IO realtime, and Better Auth authentication.

## Folder Structure

- `src/` — Backend application code
- `config/` — Environment and security configuration
- `database/` — PostgreSQL migrations, schemas, and Drizzle setup
- `storage/` — File processing and Cloudinary configuration
- `scripts/` — Development and maintenance scripts
- `tests/` — Integration and unit test suite
- `docs/` — API documentation and architecture guides
